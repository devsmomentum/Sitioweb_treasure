# 🏴‍☠️ MapHunter: La Búsqueda del Tesoro Urbana

¡Bienvenido a **MapHunter**! Una experiencia web inmersiva diseñada para cazadores de tesoros modernos. Este proyecto combina una estética cinemática inspirada en los grandes títulos de videojuegos con una interfaz de usuario dinámica e interactiva.

## ✨ Características Principales

### 🏙️ Experiencia Cinemática
- **Hero Parallax:** Una entrada épica con un cofre legendario y una ciudad nocturna que reacciona al movimiento del scroll.
- **Action Parallax:** Sección de eventos en vivo con transiciones fluidas y estadísticas en tiempo real.
- **Diseño Premium:** Estética neón, efectos de cristal (glassmorphism) y animaciones fluidas con Framer Motion.

### 💰 La Tiendita Mágica
Equípate con poderes únicos que afectan la interfaz visualmente:
- **❄️ Congelar:** Una tormenta de nieve que detiene todas las animaciones.
- **🌑 Pantalla Negra:** Un efecto de "apagado de TV" gradual.
- **❤️ Vida:** Recuperación visual de salud.
- **🌫️ Pantalla Borrosa:** Confusión visual para el oponente.
- **🛡️ Escudo:** Aura dorada protectora.
- **🧛 Robo de Vida:** Animación de corazones ascendentes.
- **🔄 Devolución & 👻 Invisible:** Efectos espectrales y traslúcidos.

### 🏆 Ranking Mundial (Leaderboard)
- Sistema interactivo de posiciones.
- **Festejos con Confeti:** Celebra victorias con una lluvia de colores (automática o manual).
- Marcos de clase personalizados para cada jugador.

## 🚀 Tecnologías Utilizadas

- **React + Vite:** Para un desarrollo rápido y eficiente.
- **Framer Motion:** Motor principal de animaciones y transiciones.
- **Vanilla CSS:** Estilos personalizados sin frameworks pesados para un control total del diseño.
- **Lucide React:** Iconografía moderna.

## 🛠️ Instalación y Uso

1. Instala las dependencias:
   ```bash
   npm install
   ```

2. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre el navegador en `http://localhost:5173`.
